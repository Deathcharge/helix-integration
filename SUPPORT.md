# Support

Samsarix Integration Guard is beta software without a bundled support SLA.

- General, partnership, and licensing inquiries: contact@samsarix.com
- Product support: support@samsarix.com
- Security reports: follow [SECURITY.md](SECURITY.md) and use
  support@samsarix.com when private GitHub vulnerability reporting is unavailable.

Public GitHub issues are appropriate for reproducible bugs and feature requests
that contain no credentials, personal data, private payloads, or exploit details.
Include the package version, Python version, operating system, input format, exact
command or API call, expected behavior, and a synthetic reproduction.
